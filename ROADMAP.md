# Roadmap

## Done
- Saved screen points: `F7` saves the current cursor position as a named point; one active point at a time; the cursor moves there on start (optionally before every click).
- Pattern recording: `F8` records mouse (moves, clicks, wheel) and keyboard input; patterns replay in a loop via `F6` with configurable repeats and pause.

- Status overlay: click-through always-on-top badge with opacity, size, blinking and drag-to-move.

## Ideas
- Playback speed (0.5×–4×) and random timing jitter for patterns.
- Hotkeys to switch between points / patterns without leaving the game (e.g. Ctrl+1…9).
- Points and patterns relative to a game window, so they survive moving the window.
- Pattern editor: trim, delete events, change delays.
- Export / import patterns as files.
- Overlay: hotkey to show/hide it; correct placement on secondary monitors with a different display scale.
